# Bilan des sites carrières des compagnies aériennes

Dernière mise à jour : 17 novembre 2026. Depuis cette date, CLAUDE.md accepte l'extraction de pages publiques même si les conditions d'utilisation l'interdisent, mais jamais le contournement d'une protection technique.

## ✅ Lues automatiquement par le robot (7)

| Compagnie | Méthode | Remarque |
|---|---|---|
| Etihad Airways | Interface officielle SmartRecruiters | Données propres |
| Lufthansa (groupe) | Interface publique de lufthansagroup.careers | Inclut Swiss, Austrian, Lufthansa Technik… |
| Singapore Airlines | Page carrières SuccessFactors | Catégorie « Ground Professionals » |
| Qatar Airways | Page carrières Avature | 6 offres par page |
| Emirates (groupe) | Interface de emiratesgroupcareers.com | Toutes les offres, description incluse ; inclut dnata |
| Air New Zealand | Page carrières (outil Attrax) | Pas de date de publication : on note le jour où le robot voit l'offre |
| Air Tahiti Nui | Page « Job offers » | Souvent vide |

## ⛔ Protégées contre les robots (9) — on ne contourne pas

| Compagnie | Ce qui bloque |
|---|---|
| Cathay Pacific | Son interface refuse tout ce qui n'est pas un navigateur |
| SAS | Le serveur répond « service indisponible » aux robots (careers.sasgroup.net) |
| Air Tahiti | Protection Cloudflare |
| Qantas | Protection Cloudflare |
| Delta Air Lines | Protection anti-robot |
| TAP Portugal | Protection Cloudflare |
| EVA Air | Accès refusé (erreur 403) |
| Vietnam Airlines | Connexion obligatoire + captcha |
| Starlux Airlines | Captcha |

## ➖ Écartées faute d'intérêt (2)
